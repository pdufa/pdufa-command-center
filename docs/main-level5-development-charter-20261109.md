# MAIN — Permanent PDUFA prediction-development direction (2026-11-09)

**Development target:** full independently validated Level 5 FDA approval/CRL and review-timing system, integrated into the existing PREDICTIONS dashboard. Never promise 100% outcome accuracy. Preserve source history, completed work and independent reviewer authorization. This is a **versioned engineering plan**, not a claim that ChatGPT keeps performing tasks outside an authorized live run or scheduled GitHub workflow.

**Canonical tracking:** GitHub issues [#979](https://github.com/pdufa/pdufa-command-center/issues/979) (29 FOCUS trials and 23 provisional application groups), [#980](https://github.com/pdufa/pdufa-command-center/issues/980) (historical FDA blinded backtesting), and draft [PR #965](https://github.com/pdufa/pdufa-command-center/pull/965) (Stage 4 independent scientific architecture). Never re-enable GEM, GEM JR, TOP/BOTTOM or retired RAAS scoring.

## Priority 1 — same-day FOCUS preliminary research, independently verified before model release

Source/research cutoffs are **2026-11-09**, canonical FOCUS 29 exact NCT IDs from the November 8 snapshot. Preserve exact 23 cycle group identities and distinguish trials from applications, including two separate Sarepta supplements. Produce source-linked favorable evidence, counterevidence, regulatory/CMC questions and unresolved facts for each case. Clearly separate:
- *Preliminary research lean*: noncalibrated, nonofficial, openly conditional clinical/regulatory judgment;
- *FDA approval/CRL model prediction*: ABSTAIN unless independently qualified and a release gate passes;
- *Review delay/extension prediction*: separately withheld unless validated; already observed formal extensions are historical facts, not new predictions;
- *Observed final FDA action*: not a prediction, for example obstructive-HCM MYQORZO approved in December 2025.

Current first version: 23/23 **research profiles**, 29/29 NCT links. Human clinical approvals/signoffs 0; validated forecasts 0.

## Priority 2 — independent historical FDA backtesting in parallel

Original FDA published/approved records may be used as **source candidates** but not model-training examples until a denominator-complete set of original filings (including never-approved, pending, withdrawn) is independently enumerated and reviewed. Rebuild only Phase-3-readout-public evidence available before each FDA decision. Seal evidence and prediction before releasing actual outcome records to the evaluator. Prevent application-family and temporal holdout leakage. Score approval/CRL, abstention and timing separately, with full coverage and numerator/denominator; calculate calibration only from independently measured, nonleaky real outcomes. Historical records and prior accuracy from retired systems may guide source discovery but cannot be ported into new scoring.

Current historical real independent FDA model cases: 0. The 412 source-selected research candidates in Rev38 are not 412 valid labeled examples.

## Priority 3 — advanced scientific research, all Phase-appropriate methods

Continue the 40 assessment × 20 method matrix (800 positions per trial), phase-first source verification, locked SAP/multiplicity/CONSORT, counterevidence, safety and original regulatory/CMC research. Missing data are *ungraded*, not zero scientific scores. Independent qualified reviewer signatures, regulator-case identity and append-only histories required to promote clinical method grades. Existing ACACIA-HCM scientific research findings and original registry source receipts remain preserved, not replaced.

## Priority 4 — Level 5 future capability and release

After advanced research, continue with dated independent adverse and affirmative reviews, new external cohort validation, calibration, changed-information watchers, preserved prediction histories and end-to-end signed-in responsive PREDICTIONS acceptance. Each stage requires evidence, security and deployment authorization. **No production change, clinical-grade writer activation, credential expansion, alias reassignment or data licensing bypass is authorized merely by this charter.**

## Progress report after each substantial engineering step

Record actual changed commit/source receipt, trial preliminary coverage out of 29, application-level verified forecasts out of 23, independent historical cases backtested, current installation stage, tests and deployment status, and exact blockers. A green software test is not a clinical or prediction accuracy validation. Do not reset completed components to chase a numerical target.
