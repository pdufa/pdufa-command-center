# 2026 PDUFA universe: independent public-source denominator check

Checked 2026-11-19. **This is not a 296-row verified roster.** Do not infer that the difference between a site's count and 296 consists of missing PDUFA events.

## Independent source checks

1. [pdufa.bio 2026 calendar](https://www.pdufa.bio/calendar), updated Nov 18, 2026, reports **107 FDA goal dates** for **June–December 2026**. This is a partial-year *goal-date* series, not all 2026 decisions.
2. [pdufa.bio homepage](https://www.pdufa.bio/), updated Nov 18, 2026, reports **179 decided in 2026**. This is a *decision* series; it is not the same as 2026 PDUFA goal-date events. Approval actions can be early, and the scope may include events with different source coverage.
3. [Arca PDUFA calendar](https://www.arca.inc/tools/pdufa-calendar) tracks **company-disclosed future goal dates**, not a full-year retrospective census.
4. [pdufa.bio FDA decisions today](https://www.pdufa.bio/fda-decisions-today), updated Nov 19, 2026, explicitly distinguishes additional FDA approvals from events on its sourced PDUFA goal-date calendar.

**Result:** Neither 107 nor 179 validates or refutes the user's **296** total. Counting original approvals, efficacy supplements, CBER actions, amendments, resubmissions, and non-PDUFA actions under different rules can produce incompatible denominators.

## Required canonical event key and provenance

For every candidate in the requested 296-event universe record: agency (CDER/CBER), application type, application number, supplement number, review cycle, indication, original/extended PDUFA goal date, dated pre-cutoff source for that goal date, FDA action date and separately quarantined outcome source, and a canonical deduplication key. A review event is **not** necessarily one clinical trial.

Until those 296 distinct event keys are sourced, the 89 repository candidates are **provisional**, and 296 minus 89 = 207 is **arithmetic only**, not 207 verified absent events.

## Blind-review firewall

Public source counts may expose FDA outcomes; use these solely to reconcile the universe and outcomes. Do not present post-decision pages to a reviewer claiming to make a blind pre-decision prediction. Independent reviewers need a frozen pre-cutoff packet and verifiable lock.
