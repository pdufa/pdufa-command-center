# Historical forecast diagnostics

`decision-calibration.ts` computes research-only proper scoring metrics and discrimination from supplied, dated binary forecasts. `decision-calibration-holdout.ts` applies the existing frozen membership, chronology, source-review declarations, model-version and application-partition checks before exposing holdout diagnostics. Neither module creates forecasts or verifies external source truth.

AUROC measures whether approval cases receive higher forecast scores than nonapproval cases. It uses the Mann–Whitney rank statistic; equal scores share average rank and receive half credit. A constant score has AUROC 0.5 when both outcome classes exist. A single-class cohort has undefined AUROC and reports `null` with explicit class counts and `SINGLE_OUTCOME_CLASS`. Invalid, leaking, duplicate or underpowered inputs withhold discrimination alongside other metrics. Minimum sample requirements remain unchanged, and are not proof of independent validation.

Each accepted holdout forecast has a deterministic probability-error record containing its program, application, model version, subgroup, forecast/capture/action/observation chronology and cited source locations. `probabilityError` is forecast approval probability minus the supplied binary approval label. Its square contributes to Brier score; its clipped negative log likelihood contributes to log loss using the existing floor of `1e-12`. These records reconcile to the aggregate proper scores and permit review of overconfident errors. They do not invent a PASS/FAIL classification threshold, rewrite any forecast, or treat the input label as independently authenticated.

The existing contract contains numeric forecasts for the prespecified scored cohort. It does not contain a complete eligible application universe, explicit abstention records or a frozen classification/abstention policy. Therefore `abstentionCoverage` records only the number of evaluated probabilities; eligible count, abstention count and coverage remain `null`. Missing or rejected forecasts are not silently counted as abstentions, and no 100% coverage or classification accuracy is inferred from successful scoring.

No confidence interval is generated without a prespecified uncertainty method that accounts for dependence between review cycles of the same application. `uncertainty` explicitly withholds an interval and records that limitation. AUROC, calibration, evidence completeness, abstention coverage and prediction confidence are different quantities. A defined diagnostic value does not certify a validated model, genuinely unseen evaluation or improved predictive accuracy.

Regression fixtures exercise known arithmetic, tied scores, reversed ranking, single-class cohorts, score reconciliation, deterministic error ordering and leakage rejection. They remain synthetic test inputs and are never reported as observed FDA prediction performance. Product outputs remain research-only with `validatedPredictionAccuracy: false` and `tradeAuthorized: false`.
