# 100-case historical Level 1 blind-backtest gate

**Status: BLOCKED — zero genuine blind predictions generated.** The 100-case candidate manifest is `data/backtest/blind_inputs/2026-l1-blind100-candidate-manifest.csv`. Selected 100 candidates from 179 archive positions, skipping 29 exact drug-and-action-date duplicates across all positions. This is **not** verified application-level deduplication: supplements and indication differences can share drug/action dates, and same application can have differing product strings. Original action dates were used ONLY by the selector for provisional deduplication; the resulting worker-facing manifest does **not** include them, outcomes, or outcome URLs.

**Hard requirements before any prediction is called blind:**

1. Independent outcome custodian creates a *new private isolated environment* and places actual outcomes and FDA action dates in a separate location inaccessible to the predictor, including Git history, logs, tools and web search of post-cutoff material.
2. Verify each selected application number, indication, supplement/review cycle and original PDUFA goal date from pre-cutoff public evidence. The 100 candidates are not yet certified distinct FDA applications.
3. Assemble immutable per-case evidence packets containing only sources published by the documented cutoff. A title and ticker alone cannot support a scientific prediction.
4. Run a fresh outcome-unexposed model/process with no access to this conversation or the historical outcome-bearing repo. Lock prediction, confidence, cutoff, source hashes, model version and timestamp in append-only storage **before** the custodian reveals outcomes.
5. The custodian reconciles decisions, exclusions and abstentions after locking. Report accuracy on all eligible locked calls, coverage and abstentions separately. Retrospective predictions generated by an outcome-exposed reviewer are never labeled blind.

**Why this is not yet finished:** This repository branch already contains outcome-bearing archive files and outcome-exposed analyses; simply hiding CSV columns in the same repository cannot establish outcome isolation. No independent worker, evidence packets, or prediction lock was run in this change. No accuracy score is valid yet.
