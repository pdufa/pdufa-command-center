# Independent installation progress after permanent retirement

The root `AGENTS.md` is the permanent policy for active analysis. Legacy ratings are not an installation prerequisite and cannot certify scientific investigation, an FDA outcome, timing, or certainty.

The live installation evidence panel reads only the independent Deep Medical Intelligence processing inventory and the separate read-only FDA source audit. It does not request a legacy assessment feed, compute ratings, dispatch scans, restart installation tasks, or write acceptance records. A missing or malformed independent inventory stays unavailable rather than falling back to ratings.

The original fifteen-section master task catalog, dated installation snapshots, and saved task-evidence JSON remain intact. Active progress is a projection using original stable task IDs. Retired requirements are excluded from the active queue and denominator; exclusion does not count as additional work completed. Existing unrelated task IDs, statuses, timestamps, and evidence URLs remain preserved. The live task API and progress UI use the same projection.

The broader historical installation tracker and independent twelve-level medical investigation are different inventories. Historical SCIENCE-40 labels or thirteen broad installation segments must not be relabeled as completed medical-investigation levels. The independent preview reports actual metadata screening, source extraction, reviewed trials, incomplete investigations, and application decisions separately; source counts alone do not establish scientific acceptance.

Regression coverage includes stable IDs, retirement filtering, untouched acceptance records, source-count reconciliation, rejection of malformed inventories, and the separation of document retrieval from calibrated prediction acceptance. Existing dated gate-summary and chart tests remain applicable.
