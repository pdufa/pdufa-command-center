# Main PDUFA technical installation — reviewer-free acceptance scope

Decision: October 25, 2026. The owner has removed mandatory human reviewer enrollment, reviewer-key generation and reviewer encrypted-handoff completion from the **main technical installation** prerequisites.

## Technical installation scope

The installation can be built, exercised and accepted on reproducible engineering evidence for: frontend and backend deployment, Pipeline restrictions, GEM JR/GEM/WT independence and existing FS/FA associations, registry ingestion, scans and result dates, data-source health, automated reporting, backups and recovery, and authenticated read-only production probes.

There is no requirement to enroll a reviewer, supply public/private reviewer keys, assign a custodian, or transfer private FDA visual packets before completing any of those technical tasks. Legacy historical research-review workspaces can remain dormant and optional; they must not appear as required user actions for normal platform operation.

## Separate scientific and predictive claims

Eliminating enrollment is not FDA data verification or model calibration. Scientific readiness remains dependent on exact trial/program identity, source provenance, 40 investigation inputs, dated evidence, uncertainty and unresolved contradictions. Validated FDA approval probabilities additionally require source-supported original application-cycle outcomes with a complete, appropriate approval/nonapproval denominator, predecision feature dates, leakage checks, chronological holdouts and measured calibration. Until demonstrated, ratings and probabilities must stay clearly research-only / unvalidated or unavailable, as appropriate.

A future evidence workflow may use reproducible source checks and auditable data validation without making a named reviewer or encryption-key ceremony a general installation condition. Existing private-data protections must not be bypassed; if a private evidence exchange is ever used, applicable access and encryption safeguards remain in force.

## Non-goals

This scope decision changes no scan, GEM JR/GEM/WT restriction or FS/FA association, production credential, paid infrastructure, trade permission, FDA outcome label, score promotion, training eligibility, historical model accuracy or probability. It does not itself turn an unverified acceptance gate green.
