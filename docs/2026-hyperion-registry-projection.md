# HYPERION historical registry source receipt

The research package for PDUFA26-TIMING-035 retains a compact JSON
transcription of the fields verified in ClinicalTrials.gov history version
57 on November 19, 2026. Version 57 was submitted May 13, 2026 and posted
June 8, 2026, before the August 22, 2026 cutoff. The pinned browser panel
showed NCT04811092, terminated status, Phase 3, interventional design,
randomized parallel assignment, treatment purpose, double masking
(participant and investigator), enrollment 321 actual, and the primary
endpoint Median Time to Clinical Worsening with a time frame up to
approximately 35 months. The values also agreed with the corresponding
fields of the official API response retrieved on November 19. [Pinned
ClinicalTrials.gov record][revision] · [Official study API][api]

The digest in the research package covers the saved transcription. The
archived JSON response was unavailable, so the package omits the remainder
of the current API response. It preserves the original posting date and the
actual date of retrieval and verification as distinct dates.

The journal reports 320 included participants, 160 in each analyzed arm.
That analysis cohort differs from the registry's 321 actual enrollment
field. The package keeps the two denominators attached to their respective
definitions. [HYPERION primary article][journal]

The package documents 11 reviewed criteria and 14 criteria marked
UNKNOWN with evidence-specific reasons. The trial-to-submission link uses
the sponsor's pre-cutoff SEC filing and an independently reconciled
outcome-free FDA metadata handoff. This partial review cannot support a
directional result by itself. [Merck SEC exhibit][filing]
